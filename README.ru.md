# MarkMirror

## Назначение

MarkMirror — браузерный Markdown-редактор с панелями редактирования и предпросмотра.

## Веб-адрес

<https://mark-mirror.d9911.org/>

## Подтверждённые возможности

- Редактирует Markdown и обновляет текстовый и HTML-предпросмотры; встроенный парсер поддерживает заголовки, форматирование, ссылки, изображения, списки, таблицы, списки задач, fenced code blocks, цитаты и inline HTML.
- Динамически загружает редактор CodeMirror и использует простой редактор, если этот импорт не выполнен.
- Импортирует файлы `.md` и `.txt`, экспортирует текущее содержимое в Markdown или HTML и очищает редактор.
- Предоставляет настройки автодополнения, синхронной прокрутки, выбора парсера, встроенных стилей экспорта, подсветки Markdown и масштаба предпросмотра.
- Предоставляет поиск и замену, в том числе с регулярными выражениями, учётом регистра, целыми словами и подтверждением, а также панель аналитики.
- Хранит содержимое документа и настройки в браузерном `localStorage`.
- Содержит web manifest; `PWAManager` регистрирует `sw.js` и обрабатывает запрос установки, когда его предоставляет браузер. Service worker кэширует статические файлы того же origin. Это описание включённой реализации; поддержка браузером и доступность ресурсов определяют её работу.

## Использование

1. Введите Markdown в редакторе или импортируйте файл `.md`/`.txt`.
2. Откройте предпросмотр и при необходимости используйте настройки, поиск/замену или аналитику.
3. Экспортируйте документ в `.md` или `.html`, когда это нужно.

## Локальная разработка и сборка

В репозитории нет package manifest, lockfile или локальной конфигурации сборки. Это статическое приложение на ES-модулях: при проверке загрузки модулей или работы service worker отдавайте репозиторий через локальный HTTP-сервер. Локальные команды установки или сборки не определены.

## Структура

- `index.html` определяет интерфейс, импортирует внешние браузерные библиотеки и загружает модуль приложения.
- `src/script/` инициализирует приложение и элементы выбора языка.
- `src/ui/` содержит компоненты редактора, предпросмотра, аналитики и поиска/замены; `src/utils/` содержит помощники парсинга, хранилища, файлов, аналитики, действий редактора и PWA.
- `manifest.json` определяет manifest приложения, `sw.js` содержит стратегию same-origin кэширования, а `src/tests/` — браузерные тесты Markdown-парсера.

## Технологии и runtime-зависимости

Приложение использует браузерные HTML, CSS, JavaScript-модули, `localStorage`, Web App Manifest и Service Worker API. Документ загружает модули CodeMirror 6 с esm.sh, Highlight.js 11.9.0 с cdnjs, а DOMPurify 3.0.5 и Marked 9.1.6 — с jsDelivr. Конфигурация Node.js-зависимостей не отслеживается.
